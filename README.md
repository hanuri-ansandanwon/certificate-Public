# 한우리 안산단원지부 수료증 만들기

엑셀 명단을 올리면 한 명당 한 장씩 수료증 PDF를 만들어 주는 페이지예요.

- 엑셀 칸: 이름 · 학교 · 학년 · 수료 단계 · 비고 (`assets/수료증_명단_양식.xlsx`)
- 수료일은 매년 12월 1일로 고정돼요 (1~2월에 만들면 지난해 12월 1일).
- 하단 서명: 한우리독서토론논술 안산단원지부 / 지부장 이미진
- 명단은 브라우저 안에서만 처리되고 서버에 저장되지 않아요.

## 파일
- `index.html` — 화면
- `cert.js` — 엑셀 정리 규칙(학교·학년·단계 이름 바꾸기)과 PDF 그리기
- `assets/` — 글꼴(Noto Serif CJK KR, OFL), 워터마크, 엑셀 양식
- `lib/` — SheetJS, pdf-lib, fontkit

단계 이름 줄임말을 더하려면 `cert.js`의 `COURSE_RULES`에 한 줄 추가하면 돼요.
